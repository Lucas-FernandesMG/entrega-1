# Desafio Digital Twin - Frontend (Entrega 1)

## Tecnologias utilizadas

- **Expo CLI**: Framework para desenvolvimento com React Native.
- **React Navigation**: Biblioteca para navegação entre telas.
- **Axios**: Cliente HTTP para requisições.
- **Victory Native**: Biblioteca para renderização de gráficos nativos.
